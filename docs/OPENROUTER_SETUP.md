# OpenRouter: запись свободной фразой

Клиент пишет боту «хочу на консультацию завтра после обеда» — и сразу видит
свободное время на этот день. Чтобы понимать такие фразы, бот обращается к
языковой модели через OpenRouter.

Без ключа всё остальное работает как обычно: бот записывает кнопками, а на текст
отвечает «пока понимаю только кнопки».

---

## Как это работает

1. Фраза клиента уходит в модель вместе со списками услуг и специалистов и
   готовым календарём на 14 дней вперёд.
2. Модель возвращает **разбор**, а не действие: что клиент хочет, какую услугу,
   к кому, какой день и какое окно времени.
3. Система сверяет разбор со справочниками и открывает обычный диалог записи на
   первом недостающем шаге.
4. Время клиент выбирает кнопкой и подтверждает кнопкой — точно так же, как без
   AI.

Модель не пишет в календарь, не создаёт и не отменяет записи — у неё просто нет
такого пути. Подробнее — [ARCHITECTURE.md](ARCHITECTURE.md), решение 7.

## Почему OpenRouter

Один ключ ко множеству моделей, а смена модели — одна строка в `.env`, без
правки кода. Модель по умолчанию — `qwen/qwen3-max`: хорошо держит русский язык и
поддерживает строгие JSON-схемы, поэтому ответ приходит в заданной форме, а не
свободным текстом.

---

## Получение ключа

1. Зарегистрируйтесь на https://openrouter.ai
2. Пополните баланс: **Credits → Add credits**. Для начала хватит 5 долларов —
   разбор одной фразы стоит около десятой доли цента.
3. **Keys → Create key**, имя произвольное, например `booking-bot`.
4. Скопируйте ключ вида `sk-or-v1-...` — **он показывается один раз**, потом
   только удаление и создание нового.

## Перенос в конфигурацию

Впишите в `.env` на сервере (в git этот файл не попадает):

```
OPENROUTER_API_KEY=sk-or-v1-...
OPENROUTER_MODEL=qwen/qwen3-max
OPENROUTER_TEMPERATURE=0.2
OPENROUTER_MAX_TOKENS=2000
```

После правки перезапустите контейнеры: настройки читаются при старте.

```bash
docker compose -f docker-compose.prod.yml up -d
```

| Параметр | Смысл |
|---|---|
| `OPENROUTER_MODEL` | Любая модель из каталога OpenRouter с поддержкой structured outputs |
| `OPENROUTER_TEMPERATURE` | 0.2 — почти детерминированный разбор. Поднимать не нужно: здесь нужна предсказуемость |
| `OPENROUTER_MAX_TOKENS` | Потолок ответа. Для разбора код всё равно ограничивает его 400 токенами |

## Проверка

- `/admin/settings` — строка «OpenRouter (AI)» зелёная и показывает модель.
- `https://ваш-домен/health` — `"ai_configured": true`.
- Живой прогон с настоящей моделью:

```bash
python scripts/ai_probe.py
```

Пять фраз разного вида, одна из них заведомо бессмысленная. Прогон на
`qwen3-max` 10 сентября 2026:

```
✓ «хочу на консультацию завтра после обеда»        → book, Консультация, 2026-09-11, 12:00–17:00
✓ «запишите к Сергею на стрижку в пятницу на 11»   → book, Стрижка мужская, Сергей Егоров, 2026-09-11, 11:00
✓ «есть что-нибудь в понедельник вечером?»         → book, 2026-09-14, 17:00–21:00
✓ «а когда я записан?»                             → my_bookings
✓ «сколько будет дважды два»                       → unknown
Действие распознано верно: 5 из 5
```

Ответ приходит за 3–4 секунды; пока модель думает, клиент видит «печатает…».

**Меняете модель — сначала прогон.** Итог ниже «5 из 5» означает, что эта модель
для разбора не годится, какой бы дешёвой она ни была.

## Сколько это стоит

Один разбор на `qwen3-max` — около 900 токенов запроса (инструкция, календарь,
справочники) и полсотни токенов ответа. По ценам OpenRouter на сентябрь 2026
($0.78 за миллион входных токенов, $3.90 за миллион выходных) это **около
$0.001 за фразу**: тысяча фраз — примерно доллар.

Дешевле в 3–4 раза — `qwen/qwen3-235b-a22b-2507`, она тоже поддерживает строгие
схемы. Прогоном `ai_probe.py` не проверялась: перед переходом прогоните.

### Ограничение расходов

- **В коде:** не больше 20 разборов в час на одного клиента, сообщения длиннее
  500 символов обрезаются. Кнопки меню и команды в модель не уходят вообще.
- **В OpenRouter:** на https://openrouter.ai/settings задайте месячный потолок.
  Ключ, попавший не в те руки, потратит ровно столько, сколько вы разрешили.

---

## Что уходит в модель

Только текст сообщения клиента, названия услуг, имена специалистов и календарь
дат. **Имени, телефона и Telegram ID клиента в запросе нет.** В лог пишется
только результат разбора (`book`, `unknown`…), сам текст сообщения — нет.

## Безопасность ключа

Ключ — это ваши деньги. Не пересылайте его в открытые чаты и не коммитьте в git.
Утёк — удалите его на https://openrouter.ai/keys и создайте новый; правка `.env`
и перезапуск займут минуту.
