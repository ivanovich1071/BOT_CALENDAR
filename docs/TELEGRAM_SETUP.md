# Создание Telegram-бота (@BotFather)

> Выполняется за 2 минуты. Для разработки — один тестовый бот,
> при передаче заказчику — он создаёт СВОЕГО бота тем же способом.

## Шаги

1. Откройте в Telegram: https://t.me/BotFather
2. Команда `/newbot`
3. Введите **имя** бота (видно клиентам), например: `Запись | Салон`
4. Введите **username** — обязан заканчиваться на `bot`,
   например: `my_salon_booking_bot`
5. BotFather пришлёт сообщение с токеном вида:

   ```
   1234567890:AAExample1234567890_abcdefghijklmnopqrstuvwxyz
   ```

6. Впишите токен в `.env`:

   ```
   BOT_TOKEN=1234567890:AA...
   ```

   (или пришлите мне в чат — я внесу и проверю запросом `getMe`).

## Рекомендуемая доводка (необязательно)

- `/setdescription` — текст «О компании», виден в пустом боте.
- `/setuserpic` — аватар.
- `/setmenubutton` — кнопка меню (сделаем «Записаться»).

## Проверка

После заполнения `.env` проверяем: запрос
`https://api.telegram.org/bot<ТОКЕН>/getMe` должен вернуть имя бота,
после чего запускается `python -m app.bot.main` и `/start` в боте
должен отвечать.

## Безопасность

- Токен = полный контроль над ботом. Не пересылайте в открытые чаты,
  не коммитьте в git.
- При утечке: BotFather → `/revoke` → новый токен.
