# Создание Telegram-бота (@BotFather)

> Две минуты. Для разработки — один тестовый бот; при передаче заказчику он
> создаёт СВОЕГО бота тем же способом (см. [TRANSFER.md](TRANSFER.md)).

## Шаги

1. Откройте в Telegram: https://t.me/BotFather
2. Команда `/newbot`
3. Введите **имя** бота — его видят клиенты, например: `Запись | Салон`
4. Введите **username** — обязан заканчиваться на `bot`,
   например: `my_salon_booking_bot`
5. BotFather пришлёт сообщение с токеном вида:

   ```
   1234567890:AAExample1234567890_abcdefghijklmnopqrstuvwxyz
   ```

6. Впишите токен в `.env` на своей машине или на сервере:

   ```
   BOT_TOKEN=1234567890:AA...
   ```

   Токен — это полный контроль над ботом. Вписывайте его сами, не пересылайте
   в переписке. Если он всё-таки где-то засветился: BotFather → `/revoke` →
   новый токен в `.env` → перезапуск.

## Оформление (необязательно, но клиенту приятнее)

| Команда BotFather | Что задаёт |
|---|---|
| `/setdescription` | Текст в пустом чате — «о компании», до первого сообщения |
| `/setabouttext` | Короткое описание в профиле бота |
| `/setuserpic` | Аватар |
| `/setcommands` | Список команд по кнопке «Меню» |

Для `/setcommands` подойдёт:

```
start - Начать и открыть меню
help - Как это работает
cancel - Прервать текущий диалог
```

## Проверка

Токен вписан — запускаем бота:

```bash
.venv\Scripts\python -m app.bot.main
```

В логе должно появиться `Бот @имя запущен, слушаю обновления`. После этого
`/start` в самом боте отвечает приветствием и меню из трёх кнопок.

Если токен пустой или неверный, бот скажет об этом при старте, а не упадёт
молча. Проверить токен отдельно можно запросом
`https://api.telegram.org/bot<ТОКЕН>/getMe` — он вернёт имя бота.

Что видит клиент дальше и как менять тексты — [BOT.md](BOT.md).
